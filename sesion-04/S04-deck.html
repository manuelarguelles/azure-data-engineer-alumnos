Blob plano y ADLS Gen2 se parecen en la URL, no en la operación★★

El hierarchical namespace no cambia el protocolo: sigue siendo Blob API y ABFS. Cambia la semántica del espacio de nombres y el control de acceso.

La cuenta real: hierarchical namespace habilitado★★

El hierarchical namespace se decide al crear la cuenta; no se activa después con un clic. Si creaste un Blob común, hay que recrear la cuenta.

Las zonas se ven como contenedores★★

Un contenedor por zona es una convención legible. También se puede usar una jerarquía de carpetas; lo importante es que el nombre y el permiso coincidan con la zona.

Una convención de rutas que se entiende sin abrir el archivo★★

abfss://bronze@stpededemobrs001.dfs.core.windows.net/
  pedidos/
    fecha_carga=2026-10-10/
      orders.csv
      order_items.csv
  productos/
    fecha_carga=2026-10-10/
      products.csv

abfss://gold@stpededemobrs001.dfs.core.windows.net/
  ventas_por_dia/
    anio=2026/mes=10/dia=10/
      parte-0001.parquet
  • abfss:// es el protocolo de ADLS Gen2 para motores como Spark.
  • La ruta incluye contenedor, cuenta y partición.
  • El nombre de la partición debe coincidir con el filtro frecuente.

Ejercicio · Predice el acceso leyendo un ACL★

user::rwx
user:analistas:r-x
group::---
mask::r-x

# Preguntas:
# 1. ¿analistas puede listar?
# 2. ¿analistas puede leer?
# 3. ¿analistas puede escribir?
# 4. ¿qué hace mask?
  • Ejemplo resuelto: analistas puede listar y leer; no escribir; la máscara r-x recorta la entrada nombrada.
  • Si mask fuera ---, analistas no accedería aunque su entrada diga r-x.
P.E. Data Engineer · Azure · M4S04 · 13/27

El ACL decide quién ve cada zona★★

Define ACL por defecto en la carpeta padre para que los archivos nuevos hereden el permiso. Sin default, cada pipeline tendría que reasignar permisos.

P.E. Data Engineer · Azure · M4S04 · 14/27

Un ACL se lee como dueño, grupo y otros★

# Permisos de una carpeta de oro
user::rwx
group::r-x
other::---

# ACL por defecto para archivos nuevos
user::rw-
group::r--
other::---

# Verificar desde el CLI de Azure
az storage fs access show \
  --account-name stpededemobrs001 \
  --file-system gold \
  --path ventas_por_dia \
  --auth-mode login
  • user dueño, group grupo, other resto.
  • rwx: leer, escribir, ejecutar/atravesar.
  • La ACL por defecto se hereda a los hijos nuevos.

Ejercicio · Default ACL y herencia: ¿el archivo nuevo lo hereda?★

Escenario¿Hereda?Por qué
Carpeta con default ACL + archivo nuevoSíEl default se aplica a los hijos nuevos
Carpeta sin default + archivo nuevoNoNo hay regla que heredar
Cambio el default después de crear el hijoNoEl hijo existente conserva su ACL
Muevo un archivo a otra carpetaDependeLa operación puede reasignar o conservar ACL

Ejemplo resuelto: define el default en la raíz de la zona antes de cargar; si lo cambias después, no actualiza los hijos existentes.

Ciclo de vida: mover, archivar y borrar con una política★★

La política de ciclo de vida mueve o borra por antigüedad y último acceso. Se define por prefijo de ruta, igual que las zonas.

P.E. Data Engineer · Azure · M4S04 · 18/27

Ejercicio · Convierte la política de ciclo de vida en una regla★★

{
  "rules": [{
    "enabled": true,
    "name": "bronze-logs",
    "type": "Lifecycle",
    "definition": {
      "filters": {"blobTypes":["blockBlob"], "prefixMatch":["bronze/logs/"]},
      "actions": {"baseBlob": {
        "tierToCool": {"daysAfterModificationGreaterThan": 90},
        "delete": {"daysAfterModificationGreaterThan": 365}
      }}
    }
  }]
}
  • Ejemplo resuelto: Cool a 90 días y delete a 365 para bronze/logs/.
  • Cool tiene mínimo 30 días y Archive 180; borrar antes de tiempo puede generar cargos.

Cinco preguntas de salida

¿Qué habilita el hierarchical namespace?

Carpetas reales, operaciones atómicas y ACL POSIX; se decide al crear la cuenta.

¿RBAC o ACL para que un analista lea solo oro?

ACL en la carpeta de oro; RBAC puede complementar el acceso al recurso.

¿Por qué no usar la clave de cuenta para dar acceso?

Es la llave maestra; un secreto filtrado abre todo el lago. Usa identidad administrada, SP o SAS acotado.

¿Qué hace una política de ciclo de vida?

Mueve o borra datos por antigüedad/uso, por ejemplo hot → cool → delete.

¿Qué verifica que el lago quedó bien?

Archivos en bronce, contenedores correctos y permisos probados: analista lee oro y no bronce.
