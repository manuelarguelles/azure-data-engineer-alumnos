# Crear una suscripción gratuita de Azure

Video de acompañamiento (1:45): `assets/video/azure-free-trial.mp4`.

## Antes de comenzar

Prepara una cuenta de Microsoft o GitHub, un teléfono que pueda recibir mensajes o llamadas y una tarjeta de crédito o débito no prepago. La [oferta gratuita de Azure](https://azure.microsoft.com/es-mx/pricing/purchase-options/azure-account) está disponible para nuevos clientes elegibles e incluye un crédito de USD 200 durante 30 días. Revisa las condiciones vigentes al registrarte.

## Pasos

1. Abre la página oficial y selecciona **Probar Azure gratis**.
2. Inicia sesión con tu cuenta de Microsoft. Si aún no tienes una, selecciona **Crear una cuenta** y completa el registro.
3. Completa el país o región, nombre, apellidos y datos de contacto. Usa la dirección de facturación asociada a tu tarjeta.
4. Selecciona el código de país y escribe tu teléfono. Elige mensaje de texto o llamada e introduce el código que recibas.
5. Completa el titular, número de tarjeta, vencimiento y código de seguridad en el formulario oficial. Revisa la dirección de facturación y el país o región. Puede aparecer una retención temporal de verificación.
6. Revisa tus datos, la oferta y los consentimientos. Lee las condiciones y confirma el registro. Completa las comprobaciones adicionales que solicite Azure.
7. Una vez aprobado el registro, abre el [portal de Azure](https://portal.azure.com), busca **Suscripciones** y comprueba el estado **Activo** y la oferta elegida.

## Al finalizar la prueba

Para continuar después de 30 días o de agotar el crédito, revisa las opciones y condiciones de pago por uso. La oferta gratuita solo está disponible una vez por cliente.

Referencia de los campos de registro: [Microsoft Learn](https://learn.microsoft.com/es-es/azure/cost-management-billing/troubleshoot-subscription/troubleshoot-azure-sign-up).
